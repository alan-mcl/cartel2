# Asset backlog

Inventory of **art and audio still to supply** for Cartel production. It reflects the catalog and `assets/` tree as of the latest content pass (eleven E-world hubs, thirty-eight minor beacons, three hundred fifty-nine unique location banners, forty-three corporation logos).

**How to read status**

| Status | Meaning |
|--------|---------|
| **Placeholder on disk** | A file exists so Godot imports and CI pass; it was generated by a repo script or early POC art and should be **replaced in place** (same path and filename). |
| **Procedural runtime** | No dedicated asset; code draws the effect (exhaust, lasers, N-space field). |
| **Missing path** | Nothing in the tree yet. *Currently none* — every `res://` path referenced by catalogs resolves. |

Authoring dimensions and import rules: [sprite_sizes.md](sprite_sizes.md). Audio logical ids (unchanged when swapping files): [audio.md](audio.md) and [`data/audio/library.json`](../../../data/audio/library.json).

Regeneration helpers (skip existing files):

- Planets / hulls / starfields: `python3 scripts/tools/generate_placeholder_art.py`
- Location banners: `python3 scripts/tools/generate_location_banners.py`
- Chassis headers and module icons: `python3 scripts/tools/generate_ui_ship_module_art.py`
- Audio stubs: `python3 scripts/tools/generate_placeholder_audio.py`

After replacing art: `godot --path . --headless --import --quit`.

## Suggested delivery order

1. **E-world planet pairs** (22 PNG) for hubs players live on — unlocks city-mall sidecars and globe presentation.
2. **Core location banners** — Proxima, Tycho, Bela hubs plus the three new neighbourhoods (20 files) before the long tail of corporate offices.
3. **Audio** — exploration + habitat loops and UI SFX (small file count, high feel impact); keep `menu_01` unless replacing intentionally.
4. **Hull SVG refresh** — Pegasus and Wolff first (defaults and combat sandboxes), then freighter / scout lines.
5. **World SVG upscale** — habitats and yards when ready to break shared Proxima silhouettes.
6. **Minor-world albedo** — only where beacons are story-critical (e.g. `tartarus`, `nocturn`, belt habs).

## Maintenance

When adding catalog locations or sectors, run the placeholder generators so paths exist, then append rows to this doc (or re-run an inventory script). Do **not** commit `.godot/` import caches.

For implementation bugs that look like art issues, track code in [backlog.md](backlog.md); track **files to paint or record** here.
